# Тропа — соцсеть туристических маршрутов

Турист проходит маршрут с трекером, загружает трек, оставляет пометки и фото на карте.
Остальные выбирают, куда идти, по отзывам и подсказкам тех, кто там уже был.

## Запуск

Нужен только Node.js 22.13+ (зависимостей нет, база — встроенный SQLite).

```bash
cd tropa
npm run demo    # сервер + демо-данные, http://localhost:3000 (вход: ayuna@demo.tropa / demo12345)
npm start       # сервер без демо-данных
npm test        # тесты API
```

Переменные: `PORT` (по умолчанию 3000), `DATA_DIR` (база и фото, по умолчанию `tropa/data`).
В продакшене ставьте за HTTPS-прокси (nginx/Caddy), который передаёт `X-Forwarded-Proto` — тогда cookie получит флаг `Secure`.
Геолокация в браузере работает только по HTTPS.

## Что умеет

- **Трек из трекера**: импорт GPX/KML (Apple Watch, Garmin, Strava, Google Карты) или запись в браузере с доступом к геопозиции.
  Дистанция, время и набор высоты считаются на сервере.
- **Пометки и фото** в точках маршрута — их может оставить любой вошедший пользователь.
- **Отзывы с оценкой** — один на человека, свой маршрут оценить нельзя.
- **«Куда пойти»**: поиск по месту и названию, карта, рейтинг.
- **Профиль**: стена (записи, фото, пройденные маршруты) и вкладка «Маршруты»; приватные маршруты видит только автор.
- **Поделиться** ссылкой и **скачать GPX**, чтобы пройти по чужому треку.
- **Профиль высот**: ведёте по графику — метка идёт по карте; кнопка «Пройти маршрут» проигрывает путь целиком.
- **Пейзажные обложки**: у каждого маршрута свой горный пейзаж (`public/scene.js` рисует его по номеру маршрута),
  слои сдвигаются за курсором. Фото из пометки заменяет пейзаж. Светлая и тёмная темы.

## Демо без сервера

```bash
node demo/build.js      # собирает demo/dist
```

`demo/dist/index.html` открывается с любого статического хостинга: интерфейс тот же, но данные живут в памяти
вкладки (`demo/demo-api.js`), а вместо карты — условный рельеф, не связанный с реальной местностью.

## Ограничения

- Прямой синхронизации с Apple Health / Google нет: веб-приложению эти данные недоступны, нужен файл трека.
  Автосинхронизация — это нативное iOS/Android-приложение (HealthKit / Health Connect) или OAuth Strava/Garmin.
- Запись в браузере останавливается при погашенном экране.
- Нет оплаты и тарифов, подписок на людей, восстановления пароля, ограничения частоты запросов.
